## Quick Overview
 
💡 **Context** - Our project group was tasked with developing the SPAM system (Autonomous Motor Production System / *Système de Production Autonome de Moteurs*).  
The objective of SPAM is to autonomously produce motors. It is composed of 5 subsystems.  
 <details>
  <summary>View the SPAM system architecture</summary>
  <p align="center">
  <img src="assets/images/Architecture_SPAM.jpg" alt="SPAM Architecture" width="750"> <br>
<em>Figure 1 – SPAM system architecture</em>
</p>
</details>  

Each team member was responsible for one subsystem. My part focused on the **communication subsystem**.  
<br>
  
🎯 **Objective** - Build the communication system in order to:  
1. Control and program the tasks of a mobile robot. 
2. Manage a database (actions, tasks, inventory)

  1. Requirements Engineering  
  2. Database Creation
